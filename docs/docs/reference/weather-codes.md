# 天気コード

表示名とアイコンは WMO 4677 の天気解釈コードに対応しています。出典は [Open-Meteo のドキュメント](https://open-meteo.com/en/docs) です。

`--json` で受け取る `weatherCode` は、この番号のままです。

## 対応していないコード

表に無いコードは `❓ 不明` と表示されます。API 側が新しいコードを足した場合は、その行を追加するだけで済みます。
